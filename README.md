# Predictive Maintenance Data Analysis

基于 Python 的工业设备传感器数据分析项目。项目使用 UCI AI4I 2020 Predictive Maintenance Dataset，对设备运行记录进行数据质量检查、统计异常筛查、故障标签验证、风险优先级排序与维护建议分析。

> 本项目中的“统计异常”用于初步风险筛查，不等同于机器故障、故障诊断或故障根因结论。

---

## 1. 项目背景

制造业设备维护通常依赖定期保养、现场巡检和报警响应。若能够从运行传感器数据中提前识别偏离常态的工况记录，就可以帮助维护人员建立更有针对性的复核队列，提高维护资源使用效率。

本项目基于公开的 AI4I 2020 模拟预测性维护数据集，完成以下分析：

- 检查数据质量；
- 基于统计阈值筛查运行异常；
- 将统计异常与真实机器故障标签交叉验证；
- 比较正常和故障记录的传感器特征；
- 根据异常指标数量构建初步风险分组；
- 输出异常初筛池与多信号优先复核清单；
- 形成可解释的维护建议。

---

## 2. 数据集说明

- 数据集：UCI AI4I 2020 Predictive Maintenance Dataset
- 原始规模：10,000 条记录、14 个源字段
- 数据文件：`ai4i2020.csv`

### 主要字段

| 字段 | 含义 |
|---|---|
| `UDI` | 样本记录编号 |
| `Product ID` | 产品编号 |
| `Type` | 产品质量变体，L/M/H |
| `Air temperature [K]` | 空气温度 |
| `Process temperature [K]` | 过程温度 |
| `Rotational speed [rpm]` | 转速 |
| `Torque [Nm]` | 扭矩 |
| `Tool wear [min]` | 刀具磨损时间 |
| `Machine failure` | 是否发生机器故障 |
| `TWF` | 刀具磨损故障 |
| `HDF` | 散热故障 |
| `PWF` | 功率故障 |
| `OSF` | 过载故障 |
| `RNF` | 随机故障 |

### 重要数据边界

- `UDI` 是记录编号，**不是实际时间戳**；因此不能将其直接解释为设备真实运行时间趋势。
- `Product ID` 在该数据集中每条记录唯一，不能用于跟踪同一台物理设备的长期劣化过程。
- `Type` 是模拟数据中的产品质量变体，不应直接称为“设备型号”或“设备类型”。
- 数据集为公开模拟数据，分析结论不能不经验证地直接外推到真实生产场景。

## 3. 项目方法

### 3.1 数据质量检查

完成以下检查：

- 数据维度与字段类型检查；
- 缺失值检查；
- 重复记录检查；
- 描述统计量计算与导出。

### 3.2 单变量统计异常筛查

对以下五项连续变量进行异常识别：

- 空气温度；
- 过程温度；
- 转速；
- 扭矩；
- 刀具磨损。

每项指标满足以下任一条件即被标记为该指标的统计异常：

1. 位于均值 ± 3 倍标准差之外；
2. 位于 1% 分位数以下或 99% 分位数以上。
